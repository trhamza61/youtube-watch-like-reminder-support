# YouTube Watch & Like Reminder Support

Support and issue tracking for the YouTube Watch & Like Reminder Chrome extension.

## Support

If you have a problem, bug report, compatibility issue, or feature request, please open an Issue in this repository.

Please include:

- What happened
- What you expected
- YouTube content type: Video / Shorts / Live / Premiere
- Chrome version
- Extension version
- Steps to reproduce the problem

## Privacy

The extension does not use analytics or telemetry and does not send user data to an external server.

Settings, reminder state, muted channels, and Smart Mode learning data are stored locally in Chrome extension storage.

## Important

The extension never automatically likes videos.

YouTube's Like button is triggered only after the user explicitly clicks Like on the reminder card.

# Türkçe Destek

YouTube Watch & Like Reminder Chrome uzantısı için destek ve hata bildirim sayfasıdır.

Bir hata, uyumluluk problemi veya özellik önerisi için bu repository içindeki **Issues** bölümünü kullanabilirsiniz.

Bildirim yaparken mümkünse şunları ekleyin:

- Ne oldu?
- Ne olmasını bekliyordunuz?
- İçerik türü: Video / Shorts / Live / Premiere
- Chrome sürümü
- Uzantı sürümü
- Sorunu tekrar oluşturma adımları

Uzantı analytics veya telemetry kullanmaz ve kullanıcı verilerini harici bir sunucuya göndermez.

Uzantı hiçbir videoyu otomatik olarak beğenmez. Beğenme işlemi yalnızca kullanıcı hatırlatma kartındaki Beğen butonuna açıkça tıkladığında gerçekleşir.
