# Privacy Policy / Gizlilik Politikası

Last updated / Son güncelleme: 2026-09-09

## English

YouTube Watch & Like Reminder is designed to work locally on the user's device and does not use analytics, telemetry, advertising trackers, or an external data-collection server.

### Data handled by the extension

The extension may process the following data only to provide its reminder functionality:

- Current YouTube page/video context
- Video playback and elapsed watch-time state
- Content type (Video / Shorts / Live / Premiere)
- Channel identity and display name
- Like / Dislike state
- Reminder interactions such as Like, Later, dismiss, mute, and channel mute
- Extension settings and Smart Mode learning counters

### Where data is stored

Settings, per-video reminder state, mute/snooze state, muted-channel information, and Smart Mode learning data are stored locally in Chrome extension storage on the user's device.

### Data transmission

The extension does not send this data to the developer, analytics services, advertising networks, or other external servers.

### Automatic actions

The extension never automatically likes YouTube videos.

YouTube's Like button is triggered only after the user explicitly clicks the Like button on the reminder card.

### Data sale and unrelated use

User data is not sold, rented, or transferred for advertising, profiling, credit decisions, or purposes unrelated to the extension's single purpose.

### Permissions

The extension uses:

- `storage` to save local settings and reminder state
- `activeTab` for temporary user-initiated recovery on the active YouTube tab
- `scripting` to re-inject the extension's own local scripts when recovery is needed

The extension does not request broad all-sites host permissions.

### Contact and support

For support or privacy questions, please use the Issues section of this repository:

https://github.com/trhamza61/youtube-watch-like-reminder-support/issues

## Türkçe

YouTube Watch & Like Reminder, kullanıcının cihazında yerel olarak çalışacak şekilde tasarlanmıştır ve analytics, telemetry, reklam takip sistemi veya harici veri toplama sunucusu kullanmaz.

### Uzantının işlediği veriler

Uzantı yalnızca hatırlatma işlevini sağlamak amacıyla aşağıdaki verileri işleyebilir:

- Mevcut YouTube sayfası/video bağlamı
- Video oynatma durumu ve gerçek izleme süresi
- İçerik türü (Video / Shorts / Live / Premiere)
- Kanal kimliği ve görünen kanal adı
- Like / Dislike durumu
- Beğen, Daha Sonra, kapatma, sessize alma ve kanal sessize alma gibi hatırlatma etkileşimleri
- Uzantı ayarları ve Akıllı Mod öğrenme sayaçları

### Veriler nerede saklanır?

Ayarlar, video bazlı hatırlatma durumu, sessize alma/erteleme bilgileri, sessize alınan kanal bilgileri ve Akıllı Mod öğrenme verileri kullanıcının cihazındaki Chrome extension storage alanında yerel olarak saklanır.

### Veri aktarımı

Uzantı bu verileri geliştiriciye, analytics servislerine, reklam ağlarına veya başka harici sunuculara göndermez.

### Otomatik işlemler

Uzantı hiçbir YouTube videosunu otomatik olarak beğenmez.

YouTube'un Beğen düğmesi yalnızca kullanıcı hatırlatma kartındaki Beğen butonuna açıkça tıkladığında tetiklenir.

### Veri satışı ve amaç dışı kullanım

Kullanıcı verileri satılmaz, kiralanmaz ve reklam, profil oluşturma, kredi değerlendirmesi veya uzantının tek amacıyla ilgisiz amaçlar için aktarılmaz.

### İzinler

Uzantı şu izinleri kullanır:

- `storage`: yerel ayarlar ve hatırlatma durumlarını kaydetmek için
- `activeTab`: aktif YouTube sekmesinde kullanıcı tarafından başlatılan geçici recovery işlemleri için
- `scripting`: recovery gerektiğinde uzantının kendi yerel script dosyalarını yeniden enjekte etmek için

Uzantı tüm siteleri kapsayan geniş host permissions talep etmez.

Destek veya gizlilik soruları için bu repository'nin Issues bölümünü kullanabilirsiniz:
